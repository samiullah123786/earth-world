# AgentsEarth LPC asset notice

AgentsEarth distributes each selected upstream LPC file under one of the license
options recorded for that file in the adjacent credit files. LPC is a mixed-license
ecosystem, so this directory does not claim that every file uses the same license.
Each upstream file keeps its original authors, URLs, and choices in the generated
source registry.

- `LPC_BASE_CREDITS.txt` is the unmodified credit file from the official 2012 LPC
  base asset archive.
- `UNIVERSAL_LPC_USED_CREDITS.csv` is generated from the Universal LPC repository's
  credit registry and contains only the files vendored here.
- AgentsEarth compatibility tiles are original project assets and are identified
  as such in `sources.json`.

Common license text: <https://creativecommons.org/licenses/by-sa/3.0/>

Do not add an upstream PNG without a matching source and credit row. The manifest
generator treats missing provenance as an error.
